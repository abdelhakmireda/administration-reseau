# 🎯 🧠 Bloc 1 — Questions simples (Compréhension de base)

👉 Objectif : vérifier qu’ils comprennent **IP / réseau / machine**

### ❓ Questions

* Une adresse IP sert à quoi ?
* Quelle est la différence entre IP et MAC ?
* Est-ce que deux machines peuvent avoir la même IP ?
* Quelle est la différence entre IP privée et IP publique ?
* Dans l’adresse `192.168.1.10`, quelle partie représente le réseau ?

---

# 📏 🧠 Bloc 2 — Questions sur les masques (TRÈS IMPORTANT)

👉 Objectif : comprendre `/24 /26 /30`

### ❓ Questions

* Que signifie `/24` ?
* Combien de bits pour les machines dans `/24` ?
* Quelle est la formule pour calculer le nombre de machines ?
* Pourquoi on fait `-2` ?

### 🎯 Exercices rapides

* Combien de machines dans :

  * `/24`
  * `/25`
  * `/26`
  * `/30`

👉 (très important de les faire à l’oral aussi)
